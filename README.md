## 0.4.14：以模块拥有关系决定收起态圆角（测试，暂不上源）

0.4.12/0.4.13 仍反馈展开转场会尖。本版回到不含全局动画钩子的安全 0.4.9 基线，只修正模块滑条识别：直接核对 MRU 主/副滑条、显示模块 sliderView、传统音量控制器主/副滑条，以及白点/夜览滑条属性；不再要求响应链同时包含 CCUIContentModuleContentContainerView。

因此真正属于这些控制中心模块的滑条，在紧凑态第一次布局时就用固定 100% 胶囊半径，期望 UIKit 从已经圆润的模型开始转场，而不是展开后才补圆角。持续采用原生填充布局；无设置面板、默认启用；没有 CALayer 全局动画 Hook、定时清理或动画抑制。

验收：只长按展开亮度模块、不要点滑条，检查紧凑态开始和过渡中间帧；再测静止填充、收起、其它控制中心模块。尚未真机确认，测试包暂不发布到插件源。
